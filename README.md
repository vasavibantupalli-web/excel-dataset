# Student Performance Analysis Using Excel

## Project Overview

This project analyzes student academic performance using Microsoft Excel. The dataset contains information about students' gender, ethnicity, parental education, lunch type, test preparation, and scores in math, reading, and writing.

The main goal is to identify performance patterns, compare scores, and understand the factors that may influence students' academic results.

## Objectives

* Analyze students' academic performance.
* Compare math, reading, and writing scores.
* Explore the impact of test preparation on scores.
* Understand performance differences based on gender and parental education.
* Create meaningful insights using Excel visualizations.

## Tools and Technologies

* Microsoft Excel
* Data Cleaning
* Sorting and Filtering
* PivotTables and PivotCharts
* Excel Formulas
* Data Visualization

## Dataset Description

The dataset includes the following columns:

* Gender
* Race/Ethnicity
* Parental Level of Education
* Lunch
* Test Preparation Course
* Math Score
* Reading Score
* Writing Score

## Project Workflow

1. Import the student performance dataset into Excel.
2. Inspect and clean the data.
3. Analyze student scores using formulas.
4. Create PivotTables to summarize the data.
5. Develop charts and visualizations.
6. Identify trends and summarize the findings.

## Key Insights

* Compare average math, reading, and writing scores.
* Analyze performance differences across student groups.
* Examine the relationship between test preparation and academic scores.
* Identify patterns that can help understand student performance.

## Conclusion

This project demonstrates how Microsoft Excel can be used for data analysis and visualization. It helps transform raw student data into meaningful insights and improves practical skills in data cleaning, analysis, and reporting.
